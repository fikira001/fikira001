## 🛡️ Featured SOC & Security Projects

### 🔬 1. Enterprise SOC Detection Lab — Threat Detection & Detection Engineering
> **Environment**: Wazuh SIEM/XDR • Sysmon • Windows 10 • Kali Linux • VMware • MITRE ATT&CK
* **Endpoint Telemetry & SIEM Integration**: Deployed Wazuh SIEM/XDR integrated with Sysmon endpoint telemetry to capture process creation, command-line activity, registry edits, and file modifications on Windows 10 endpoints.
* **Ransomware Attack Chain Simulation**: Executed an adversary attack simulation from Kali Linux covering Reconnaissance (`T1595`), User Execution (`T1204.002`), Privilege Escalation (`T1134`), Credential Dumping (`T1003`), and Shadow Copy Deletion (`T1490`).
* **Detection Gap Analysis**: Analyzed default SIEM alerting performance and identified that default Wazuh rules only triggered low-severity alerts for critical ransomware preparation steps.
* **Custom XML Rule Engineering**: Authored **3 custom XML detection rules** mapped to MITRE ATT&CK `T1490` to catch malicious execution of `vssadmin`, `bcdedit`, and `wbadmin`, elevating alert severity to **Level 12 (Critical)**.
* **Telemetry & IOC Investigation**: Extracted Indicators of Compromise (IOCs), correlated cross-host attack events, and produced a formal incident investigation report with attack timelines and mitigation strategies.
